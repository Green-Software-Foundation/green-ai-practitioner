## Contributing

All Knowledge Unit authorship follows the nine-phase flow defined in the [Course Initiation](course-initiation.md). Volunteers should be assigned a Knowledge Unit by the project lead before starting work. No rendering (video scripts, AI rulesets) begins until the Knowledge Unit has been SME-approved.
